Computer Architecture - Course Objectives
By the end of this course, students should be able to: 
1. Understand the basic organisation of digital computer, pipelining and parallelism. 
2. Explain instruction executions, ISA format and addressing mode.  
3. Evaluate performance metrics,  
4. Describe memory hierarchy 
5. Explain I/O organisation, 
6. Explain process management. 
7. Understand concurrency and synchronisation. 
8. Analyse deadlocks. 
9. Understand memory management. 
10. Explain ﬁle systems.

ITDS-211: Computer Architecture & Operating System W.Suntiamorntut, Ph.D.
Course Learning Outcomes (CLOs)
By the end of this course, students should be able to: 
CLO 1: Explain the basic organisation of a digital computer, including instruction execution, ISA formats, addressing 
modes, pipelining, and parallelism. 
CLO 2: Evaluate computer performance metrics and describe the memory hierarchy and I/O organisation. 
CLO 3: Explain process management, concurrency, synchronisation, and analyse deadlocks in operating systems. 
CLO 4: Understand memory management and ﬁle systems in operating systems. 
CLO 1← Objectives 1, 2 (Architecture fundamentals)
CLO 2← Objectives 3, 4, 5 (Performance & hardware resources)
CLO 3← Objectives 6, 7, 8 (OS process/concurrency topics)
CLO 4← Objectives 9, 10  (OS storage management)
Architecture basics → performance/hardware → OS process handling → OS storage handling
