Deﬁnition
Architecture (สถาปัตยกรรมคอมพิวเตอร์) refers to attributes of a system 
that are visible to a programmer. These attributes have direct impact on 
the logical execution of a program. (Instruction set, addressing modes, 
data types) เกี่ยวข้องกับผู้ใช้ / โปรแกรมเมอร์เป็นหลัก
Organization (โครงสร้างการจัดระบบคอมพิวเตอร์) refers to the operational 
units and their interconnections that realise the architectural 
speciﬁcations  (คําสั่งถูกทําให้เกิดขึ้นจริงอย่างไรในระดับวงจร, cache, pipeline, 
design, bus width, clock speed) เกี่ยวข้องกับวิศวกรฮาร์ดแวร์

Deﬁning Computer Architecture
■“Old” view of computer architecture: 
■Instruction Set Architecture (ISA) design 
■i.e. decisions regarding: 
■ registers, memory addressing, addressing modes, instruction 
operands, available operations, control flow instructions, 
instruction encoding 
■“Real” computer architecture: 
■Specific requirements of the target machine 
■Design to maximize performance within constraints: 
cost, power, and availability 
■Includes ISA, microarchitecture, hardware

Cache Memory
•  Multiple layers of memory between the processor and main memory 
• Is smaller and faster than main memory 
• Used to speed up memory access by placing in the cache data from 
main memory that is likely to used in the near future 
• A greater performance improvement may be obtained by using 
multiple levels of cache, with level 1 (L1) closest to the core and 
additional levels (L2, L3, etc.) progressively farther from the core
