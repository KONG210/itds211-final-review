Magnetic Disk
n A disk is a circular platter constructed of nonmagnetic 
material, called the substrate, coated with a magnetizable 
material
n Traditionally the substrate has been an aluminium or aluminium 
alloy material 
n Recently glass substrates have been introduced
n Benefits of the glass substrate:
n Improvement in the uniformity of the magnetic film surface to 
increase disk reliability
n A significant reduction in overall surface defects to help reduce 
read -write errors
n Ability to support lower fly heights
n Better stiffness to reduce disk dynamics
n Greater ability to withstand shock and damage

 Disk Performance Parameters
n When the disk drive is operating the disk is rotating at constant speed
n To read or write the head must be positioned at the desired track and at the beginning 
of the desired sector on the track
n Track selection involves moving the head in a movable -head system or electronically 
selecting one head on a fixed -head system
n Once the track is selected, the disk controller waits until the appropriate sector rotates to 
line up with the head
n Seek time
n On a movable –head system, the time it takes to position the head at the track
n Rotational delay (rotational latency)
n The time it takes for the beginning of the sector to reach the head 
n Access time
n The sum of the seek time and the rotational delay
n The time it takes to get into position to read or write
n Transfer time
n Once the head is in position, the read or write operation is then performed                                          
as the sector moves under the head
n This is the data transfer portion of the operation

n A disk array can provide high I/O

RAID 
Level 1
n Differs from RAID levels 2 through 6 
in the way in which redundancy is 
achieved
n Redundancy is achieved by the 
simple expedient of duplicating all 
the data
n Data striping is used but each logical 
strip is mapped to two separate 
physical disks so that every disk in 
the array has a mirror disk that 
contains the same data
n RAID 1 can also be implemented 
without data striping, although this is 
less common
n A read request can be serviced by 
either of the two disks that contains 
the requested data
n There is no “write penalty”
n Recovery from a failure is simple, 
when a drive fails the data can be 
accessed from the second drive
n Provides real -time copy of all data
n Can achieve high I/O request rates if 
the bulk of the requests are reads
n Principal disadvantage is the cost

RAID
Level 2
n Makes use of a parallel access 
technique
n In a parallel access array all 
member disks participate in the 
execution of every I/O request
n Spindles of the individual drives 
are synchronized so that each 
disk head is in the same position 
on each disk at any given time
n Data striping is used
n Strips are very small, often as 
small as a single byte or word
n An error -correcting code is 
calculated across corresponding 
bits on each data disk and the bits 
of the code are stored in the 
corresponding bit positions on 
multiple parity disks
n Typically a Hamming code is used, 
which is able to correct single -bit 
errors and detect double -bit 
errors
n The number of redundant disks is 
proportional to the log of the 
number of data disks
n Would only be an effective choice 
in an environment in which many 
disk errors occur

Level 5
n Organized in a similar fashion 
to RAID 4

extremely high data availability

be lost
n Incurs a substantial write 
penalty because each write 
affects two parity blocks

unusable after a certain 
number of writes

life:

cache to delay and group 
write operations
n Using wear -leveling 
algorithms that evenly 
distribute writes across block 
of cells
n Bad -block management 
techniques
n Most flash devices estimate 
their own remaining lifetimes 
so systems can anticipate 
failure and take preemptive 
action
